# ハードウェア仕様・配線ガイド（ES3C28Pベース）

## 1. ベースボード概要（ES3C28P）

| 項目 | 仕様 |
| :--- | :--- |
| **MCU** | ESP32-S3R8（Dual-core LX7 up to 240MHz） |
| **メモリ** | 512KB SRAM / **8MB OPI PSRAM** / **16MB QSPI Flash** |
| **ディスプレイ** | 2.8インチ IPS TFT（240×320、ドライバ: ILI9341V、4線SPI） |
| **タッチパネル** | 静電容量式（コントローラ: FT6336G、I2Cアドレス `0x38`） |
| **オーディオ** | ES8311 I2Sコーデック（I2Cアドレス `0x18`）＋ FM8002E モノラルアンプ |
| **充電回路** | TP4054 リポ充電管理（USB-C給電、BAT端子へ接続） |
| **その他** | MicroSD（4-bit SDIO）、WS2812互換RGB LED（GPIO 42）、BOOTボタン（GPIO 0） |

## 3. 外部接続・6ボタン並列結線

ES3C28Pの拡張IOコネクタ（1.25mm 4P）は **`GPIO 2, 3, 14, 21`** の4本のみ引き出されています。  
追加ICなしで6ボタン（十字キー4＋A/B2）を実装するため、**上(UP)とA、下(DOWN)とBをそれぞれ並列結線**します。

### 配線表
| 拡張コネクタ | ピン | 割り当て | 結線方法 |
| :--- | :--- | :--- | :--- |
| **拡張IO (4P)** | Pin 1 (`GPIO 2`) | **LEFT** | タクトスイッチ → 共通GND |
| **拡張IO (4P)** | Pin 2 (`GPIO 3`) | **RIGHT** | タクトスイッチ → 共通GND |
| **拡張IO (4P)** | Pin 3 (`GPIO 14`) | **A / UP（並列）** | AボタンとUPボタンを並列にして → 共通GND |
| **拡張IO (4P)** | Pin 4 (`GPIO 21`) | **B / DOWN（並列）** | BボタンとDOWNボタンを並列にして → 共通GND |
| **IIC / UART** | `GND` ピン | **共通GND** | 拡張IOコネクタにGNDがないためここから取得 |
| **本体基板上** | `GPIO 0` (BOOT) | **PAUSE / MENU** | 起動後はユーザーボタンとして読取可能 |

```text
  GPIO 2  ────[ SW: LEFT ]─────────────────────────┐
  GPIO 3  ────[ SW: RIGHT ]────────────────────────┤
  GPIO 14 ──┬─[ SW: A ]────────────────────────────┤
            └─[ SW: UP ]───────────────────────────┤
  GPIO 21 ──┬─[ SW: B ]────────────────────────────┤
            └─[ SW: DOWN ]─────────────────────────┤
                                                   ▼
                                       共通GND（IIC/UARTのGNDへ）
```

### 操作運用のポイント
- **全て内部プルアップ（`GPIO_PULLUP_ENABLE`）＋ Active-Low** のため、外付けプルアップ抵抗は不要です。
- ソフト側の入力抽象化により、ゲームごとに次のように使い分けます。
  - **メニュー / 4方向ゲーム**：`LEFT / RIGHT / UP(14) / DOWN(21)` を十字キー、決定を画面タッチ（またはA）。
  - **横スクロールアクション**：`LEFT / RIGHT / A(ジャンプ) / B(ダッシュ)` を主操作とし、しゃがみ・土管等は「静止中B長押し」または画面タッチで補助。
  - **音ゲー**：画面タッチ（左右タップや単押し）＋ 物理ボタンのどちらでも反応可能。

## 4. スピーカー・バッテリー接続と安全上の注意

### スピーカー（手持ち 8Ω 1W）
- ES3C28Pの **スピーカー端子（1.25mm 2P）** にそのまま接続します（FM8002Eアンプが1.5W@8Ωまで対応）。
- 音量が大きすぎる場合は、ソフト側でES8311のDACボリューム（`es8311_voice_volume_set`）およびミキサーゲインを下げて調整します。

### バッテリー（600mAh / 1200mAh LiPo 3.7V）
- ES3C28Pの **BAT端子（1.25mm 2P）** に接続します。
- ES3C28PのTP4054は標準で **約290mA〜500mA** 充電に設定されているため、**600mAh（約0.5〜0.8C）** または **1200mAh（約0.25〜0.4C）** であれば基板改造なしで安全に充電できます。
- **必ず確認すること**：
  1. **保護回路（PCM）内蔵セル**を使うこと。
  2. コネクタの **赤（＋）／黒（−）の極性** がES3C28P基板上の `+` / `-` シルク表記と一致しているか挿入前に確認すること（市販LiPoは逆極性のものが多い）。
  3. 持ち運び時の誤動作・自然放電防止のため、**バッテリーの `+` 線に小型スライドスイッチ**を直列に入れること。
